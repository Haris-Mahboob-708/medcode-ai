## 📋 Overview

MedCode AI Pro is a professional-grade medical coding assistant built to demonstrate
competency in ICD-10-CM, CPT, and HCPCS Level II coding workflows — developed as a
portfolio project for the **Medical Coder** position at **MTBC | CareCloud**, Rawalpindi.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🔍 **AI Code Analyzer** | Paste clinical notes → instant ICD-10, CPT, HCPCS suggestions |
| 📊 **Confidence Scoring** | Each code rated High / Medium / Low match confidence |
| ⚠️ **Denial Risk Flags** | Audit and denial risk indicators per code |
| 📑 **Sequencing Guidance** | Principal diagnosis & code ordering per official guidelines |
| 🛡️ **Compliance Notes** | HIPAA-aware documentation requirements per code |
| 📬 **Query Letter Generator** | Auto-generates provider clarification letter |
| ⬇️ **CSV & JSON Export** | Download full coding results for documentation |
| 📚 **Code Reference Library** | Searchable database of ICD-10, CPT, HCPCS codes |
| 📁 **Session History** | Track all codes assigned in a session with export |
| ℹ️ **Compliance Guide** | Built-in HIPAA, sequencing, and audit rules reference |
